GAMETIK – KORREKTUR PROFILBILD UND PASSWORT-RESET

WICHTIG: Die bestehende admin.html wurde nicht geändert und ist nicht Bestandteil dieses Pakets.

1) GitHub: server.js, app.js, index.html, package.json und live.js ersetzen. README.md kann ebenfalls ersetzt werden. Nicht den bestehenden data-Ordner löschen.
2) Render installiert die neuen Abhängigkeiten beim Deploy automatisch.
3) Render Environment Variablen prüfen/setzen:
   SMTP_HOST=smtp-relay.brevo.com
   SMTP_PORT=587
   SMTP_USER=dein Brevo SMTP Login (nicht der API-Key-Name)
   SMTP_PASS=dein SMTP Key
   SMTP_FROM=eine bei Brevo verifizierte Absenderadresse
   APP_BASE_URL=https://DEINE-TATSAECHLICHE-NETLIFY-ADRESSE
   R2_ACCOUNT_ID=Cloudflare Account ID
   R2_ACCESS_KEY_ID=R2 Access Key ID
   R2_SECRET_ACCESS_KEY=R2 Secret Access Key
   R2_BUCKET_NAME=exakter Bucketname
   R2_REGION=auto
   R2_PUBLIC_URL=https://deine-öffentliche-R2-Domain (ohne abschließenden Slash)
4) In Cloudflare R2 muss der Bucket-Zugriff über die angegebene öffentliche Custom Domain oder öffentliche R2-URL möglich sein. R2_PUBLIC_URL muss erreichbar sein, sonst wird das Bild zwar hochgeladen, aber nicht angezeigt.
5) Render: Deploy latest commit. Erst nach erfolgreichem Deploy testen.
6) Profilbild-Test: anmelden, Profilbild ändern, Seite neu laden, dann Profilbild in einem anderen Browser/Inkognito prüfen.
7) Passwort-Test: „Anmelden“ wählen, registrierte E-Mail-Adresse in das Feld „Benutzername oder E-Mail“ eingeben, „Passwort vergessen?“ drücken. Danach Render Logs auf SMTP-Fehler prüfen und Posteingang/Spam kontrollieren.

HINWEISE ZUR SPEICHERUNG:
- Profilbilder werden mit diesem Patch in Cloudflare R2 gespeichert; der avatar_url wird in der GameTik-State-Datei gespeichert.
- Benutzerkonten und sonstige JSON-State-Daten bleiben nur dann dauerhaft erhalten, wenn DATA_DIR auf einen tatsächlich gemounteten, beschreibbaren Render Persistent Disk zeigt. R2 ist kein Ersatz für eine Datenbank oder für die State-Datei.
- SMTP_PASS und R2_SECRET_ACCESS_KEY niemals in GitHub, Screenshots oder Chat posten.
- SMTP-Absender muss in Brevo verifiziert sein. Der Server gibt bei Fehlern nun eine verständlichere Meldung zurück.
